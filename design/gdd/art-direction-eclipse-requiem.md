## 0. 아트 필러 (Art Pillars)

ECLIPSE: REQUIEM의 모든 시각적 결정은 다음 3개 축을 기준으로 평가한다:

| 축 | 정의 | 판정 질문 |
|---|---|---|
| **Pillar A — "폐허는 성스럽다" (Sacred Ruin)** | Requiem의 모든 공간은 버려졌으나 모독되지 않았다. 신은 떠났지만 그 흔적은 경외감을 남긴다. | "이 장면이 숭고함(sublime)을 유발하는가?" |
| **Pillar B — "영혼은 빛으로 말한다" (Souls Speak in Light)** | 빛의 유일한 원천은 영혼이다. 자연 채광은 죽었다. 모든 광원은 생명 또는 그 잔존물에서 비롯된다. | "이 장면의 빛이 영혼으로부터 비롯되는가?" |
| **Pillar C — "무게는 빛과 모순된다" (Weight Contradicts Light)** | 시각적 '무게감'은 물리적 어둠이 아니라, 거대한 공간 속에서 빛나는 영혼의 왜소함에서 온다. | "공간의 스케일 대비 영혼의 스케일이 압도감을 주는가?" |

## 1. 시각적 '무게감' — ECLIPSE: REQUIEM의 정체성

### 1.1 경쟁작과의 차별화

Requiem의 독자적인 시각적 무게감은 다음 3개 축으로 구성된다:

| 경쟁작 | 그들의 무게감 | Requiem의 무게감 |
|---|---|---|
| **Bloodborne** | 건축적 억압감 — Yharnam의 좁은 골목과 첨탑이 플레이어를 짓누름 | **공허한 거대함** — 넓고 텅 빈 성당 도시의 스케일이 영혼을 왜소하게 만듦 |
| **Dark Souls** | 시간의 침식 — 모든 것이 썩고 무너져 내리는 엔트로피적 비장함 | **정지된 몰락** — 파괴되었으나 더 이상 무너지지 않는, 멈춘 붕괴의 시간 |
| **Blasphemous** | 종교적 광기 — 과장된 의식과 고문의 숭고한 변형 | **버려진 신앙** — 신이 사라진 성소. 숭배의 도구는 남았으나 대상은 부재 |

### 1.2 Requiem의 3중 무게감

```
┌─────────────────────────────────────────────────────┐
│  Requiem의 시각적 무게감                               │
│                                                       │
│  ■ 수직적 공허감 (Vertical Void)                      │
│    → 첨탑·열주·아치가 비정상적으로 높고, 카메라를      │
│      낮게 배치하여 공간의 높이를 강조                   │
│                                                       │
│  ■ 빛의 역설 (Inverse Illumination)                   │
│    → 광원은 항상 플레이어(영혼) 또는 영혼의 산물에서    │
│      비롯됨. 주변은 빛을 흡수하는 어둠                  │
│                                                       │
│  ■ 정지된 붕괴 (Arrested Decay)                        │
│    → 모든 것은 손상되었으나, 그 상태로 영원히            │
│      고정됨. 잔해는 공중에 멈추고, 균열은 확장되지 않음  │
└─────────────────────────────────────────────────────┘
```

**핵심 원칙:** Requiem의 '무게감'은 폴리곤 수나 텍스처 해상도에서 오는 것이 아니라, **조명 디자인·공간 비율·스케일 대비**에서 온다. 이 원칙은 Xbox Series S의 성능 제약을 창작적 기회로 전환하는 근거가 된다 (9장 참조).

### 1.3 스케일 원칙

| 대상 | 스케일 규칙 | 의도 |
|---|---|---|
| **건축물** | 인간 기준 3~5배 높이. 문은 2.5~3m, 천장은 12m 이상 | 영혼의 왜소함 강조 |
| **오브제** | 제단·촛대·석상은 정상 크기. 단, 공간 안에 극소수만 배치 | 공간의 공허함 대비 |
| **영혼(플레이어)** | 1:1 인간 비례. 모든 건축 대비 상대적 왜소 | Pillar C — "무게는 빛과 모순된다" |
| **군주 형상** | 원경에 배치된 거대한 석상·프레임 형태로만 존재. 근접에서는 그림자 또는 빛의 부재로 암시 | 군주가 직접 등장하지 않고, 그들의 부재가 더 큰 존재감을 발산 |

## 2. 시그니처 색채 전략

### 2.1 Requiem 기본 팔레트 (베이스)

Requiem의 배경 세계 전체를 관통하는 근본 팔레트:

```
┌─────────────────────────────────────────────────────┐
│  REQUIEM BASE PALETTE                                │
│                                                       │
│  PRIMARY (건축·대지)                                   │
│  ████████  #1a1410  Abyssal Earth  — 바닥·벽·기둥     │
│  ████████  #2a1f1a  Withered Stone  — 석재·구조물     │
│  ████████  #3d2e24  Ash Mortar     — 모르타르·틈새    │
│                                                       │
│  NEUTRAL (안개·그림자)                                 │
│  ████████  #4a3a2e  Forgotten Mist  — 원거리 안개     │
│  ████████  #5c4a3a  Dust Light      — 실내 잔광       │
│  ████████  #6b5843  Veiled Silver   — 금속·반사면     │
│                                                       │
│  SOUL ACCENT (영혼 빛) — 유일한 채도                  │
│  ████████  #7eb8da  Soul Pale       — 영혼 기본 발광  │
│  ████████  #a8d8ea  Soul Bright      — 영혼 강 발광   │
│  ████████  #3a6b8c  Soul Deep       — 영혼 잔광      │
│                                                       │
│  ACCENT (환경 내 유일한 색점)                          │
│  ████████  #8b3a3a  Dried Blood     — 희생의 흔적     │
│  ████████  #c4a45a  Tarnished Gold  — 장식·의식구     │
│                                                       │
│  ABSENCE (빛의 부재 — 순수 흑은 금지)                  │
│  ████████  #0a0810  Soul Void       — 그림자 극점     │
│  ████████  #0d0a12  Deep Requiem    — 시야 밖 공허    │
└─────────────────────────────────────────────────────┘
```

**원칙:** Requiem에는 자연 채광이 존재하지 않는다. 모든 빛은 영혼에서 발산되거나, 영혼이 남긴 잔광이다. 따라서 **채도(saturation)는 오직 영혼과 그 영향권에서만 존재**하며, 배경 세계는 근본적으로 채도가 0에 수렴한다.

### 2.2 5개 군주 영역별 차별 팔레트

각 군주 영역은 Requiem 기본 팔레트 위에 하나의 시그니처 색조가 얹히는 방식으로 차별화된다. **전체 팔레트의 대체가 아니라, 단일 악센트 색조의 추가**로 구역을 구분한다 — 이는 맵 전체의 색채 일관성을 유지하면서도 플레이어의 공간 인지를 보장하기 위함이다.

#### Grief — Sorrowfield (비탄 — 황폐한 묘지·지하 납골당)

```
시그니처 색조: 창백한 청회색 (Pale Mourning Blue)
████████  #5a7a8a   Mourning Blue (주조색)
████████  #3a5a6a   Deep Grief    (보조색)
████████  #7a9aaa   Faded Memory  (강조색)
```

- **환경 서사:** 가라앉은 묘비, 반쯤 열린 석관, 부서진 봉헌물. 비탄의 물리적 형태는 '무너짐(collapse)' — 땅이 꺼지고, 천장이 내려앉음.
- **조명:** 지하 깊숙이 갈수록 영혼 빛의 청색 비율이 증가. 지상은 안개가 청회색 필터.
- **VFX:** 안개 입자가 수직으로 서서히 가라앉는 연출. 바람은 존재하지 않음.

#### Hunger — Glutton's Gate (굶주림 — 폐허 연회장·저장고)

```
시그니처 색조: 병든 호박색 (Sick Amber)
████████  #7a5a2a   Famine Amber  (주조색)
████████  #4a3a1a   Rotting Feast (보조색)
████████  #9a7a4a   False Gold    (강조색)
```

- **환경 서사:** 전복된 연회 테이블, 산산조각 난 잔, 비어 있는 곡물 창고. 굶주림의 물리적 형태는 '비움(emptiness)' — 모든 것이 소모되고 텅 빈 공간.
- **조명:** 촛불·횃불 등 인공 광원의 비율이 가장 높은 영역. 그러나 불꽃은 항상 꺼져가고 있음.
- **VFX:** 공기 중에 떠도는 재(ash) 입자. 열기로 인한 공기 왜곡(heat shimmer)이 간헐적으로 발생.

#### Obsession — Obsidian Spire (집착 — 거대한 탑·도서관·천문대)

```
시그니처 색조: 변질된 자색 (Tainted Violet)
████████  #4a3a5a   Obsession Violet (주조색)
████████  #2a1a3a   Deep Spire       (보조색)
████████  #6a5a7a   Stained Glass    (강조색)
```

- **환경 서사:** 끝없는 책장, 부서진 천체 모형, 깨진 스테인드글라스. 집착의 물리적 형태는 '반복(repetition)' — 동일 패턴의 무한한 반복.
- **조명:** 스테인드글라스를 통과한 유색광 — 실제 태양광이 아니라 스스로 빛나는 유리(bioluminescent glass).
- **VFX:** 천장에서 서서히 회전하는 성운(nebula) 형태의 광원. 망원경·아스트롤라베의 렌즈 플레어.

#### Despair — Ashen Cathedral (절망 — 불타는 성당·순례자의 길)

```
시그니처 색조: 잿빛 진홍 (Ashen Crimson)
████████  #5a2a2a   Cathedral Ember (주조색)
████████  #3a1a1a   Pilgrim's Blood (보조색)
████████  #7a3a3a   Fading Flame    (강조색)
```

- **환경 서사:** 불타다 만 성당, 무릎 꿇은 순례자 석상의 행렬, 녹아내린 촛대. 절망의 물리적 형태는 '소진(exhaustion)' — 불이 꺼진 후의 잔열만 남은 상태.
- **조명:** 다른 영역보다 전체적으로 가장 어두움. 불타는 잔해의 잔광(ember glow)이 주요 광원.
- **VFX:** 공중에 천천히 떠오르는 불씨(ember). 바닥의 잔열 균열에서 간헐적 빛샘.

#### Wrath — Iron Crucible (분노 — 용광로·대장간·병영)

```
시그니처 색조: 냉각된 강철청 (Quenched Steel Blue)
████████  #3a4a5a   Crucible Steel (주조색)
████████  #1a2a3a   Forge Dark     (보조색)
████████  #5a6a7a   Tempered Edge  (강조색)
```

- **환경 서사:** 식은 용광로, 산산조각 난 무기 진열대, 쓰러진 병사의 갑옷. 분노의 물리적 형태는 '파쇄(shatter)' — 모든 것이 부서지고 깨진 상태.
- **조명:** 용광로의 잔열에서 나오는 청색 빛(고온 금속의 색온도). 다른 영역보다 메탈릭 반사 비율이 높음.
- **VFX:** 스파크 입자. 깨진 무기·방어구 파편이 자기장처럼 공중에 부유. 간헐적 충격파(전역 이벤트).

### 2.3 생존 상태 vs Echo 상태 색채 구분

플레이어의 상태 변화는 화면 전체의 색보정(post-process color grading)을 통해 즉시 인지 가능해야 한다:

| 상태 | 화면 색보정 | 의도 |
|---|---|---|
| **생존 (Living)** | Requiem 기본 팔레트. 영역별 시그니처 색조 정상 강도 | 현실감·위험 지각 유지 |
| **Echo (사망 직후 전환)** | 0.3초간 채도 -80%, 이후 청회색(Soul Pale) 톤으로 0.7초간 복귀 | 죽음→Echo 상태 전환의 명확한 시각적 신호 |
| **Echo 기본** | 전체 채도 -40%, 콘트라스트 -15%. 블루 틴트 +15%. 영혼을 제외한 모든 물체의 윤곽이 부드러워짐(블룸) | "당신은 더 이상 물질 세계에 완전히 속해 있지 않다" |
| **Echo 에너지 FULL (Reclaim 가능)** | Echo 기본 + 주변부 비네트(vignette)에 금색/청색 파동. 화면 가장자리에서 중심으로 영혼 빛 입자 유입 | Reclaim/소울플레어 사용 가능 상태의 직관적 전달 |

## 3. Echo 시각 언어

### 3.1 Echo 상태 전환 연출

```
타임라인: 사망 → Echo 전환 (총 1.5초)

[0.0s] 생존자 시점 사망 애니메이션 시작
[0.3s] 화면이 Soul Void (#0a0810)로 급속 페이드아웃
[0.5s] 아바타가 수직으로 붕괴하며 영혼 입자로 분해
       → 파편화된 육체 → 빛 입자 군집으로 형태 변환
[0.8s] Soul Pale 발광이 내부에서 시작되어 외부로 확산
       → 카메라가 캐릭터 내부에서 3인칭으로 빠져나오는 연출
[1.0s] Echo 상태의 반투명 영혼체가 형성 완료
[1.2s] 화면 색보정이 Echo 프로필로 전환 (2.3 참조)
[1.5s] Echo HUD 활성화. 플레이어 조작 가능.
```

**핵심 요구사항:**
- 전환 중 0.5~1.0초 구간에서 아바타의 '분해된 육체'가 영혼 입자로 흩어지는 VFX는 게임플레이 가독성을 해치지 않는 선에서 최대한 장관으로 구현
- 영혼 입자의 색상은 클래스·군주에 따라 미묘하게 변형 (Penitent → 창백한 청은색, Ravager → 탁한 호박은색 등)
- 전환 연출은 1인칭 시점을 기본으로 하나, 0.8초부터 카메라가 후퇴하여 3인칭으로 이행

### 3.2 Echo 아바타 — 영혼체 시각 디자인

| 특성 | 사양 |
|---|---|
| **불투명도** | 베이스 55%. 에너지 축적 시 최대 85%까지 상승 |
| **발광** | 내부에서 외부로의 프레넬(Fresnel) 발광. 가장자리로 갈수록 불투명도 감소 → 실루엣이 빛으로 녹아듦 |
| **형상** | 기본 인체 실루엣 유지. 단, 팔다리 말단이 파편화되어 입자로 흩어짐 |
| **텍스처** | No PBR. 반투명 머티리얼 + 이중 노멀(흐르는 액체 텍스처 오버레이)로 영혼의 유동성 표현 |
| **실루엣 왜곡** | 움직임에 따라 실루엣이 5~10% 일그러짐. 정지 시 원형으로 복원 |
| **파편화 강도** | Echo 에너지 잔량에 비례 — 에너지 낮으면 더 많은 입자가 이탈 |
| **아바타 음영** | 그림자는 드리우지 않음. 대신 바닥에 희미한 발광 영역(caustic) 생성 |

### 3.3 5개 Echo 능력별 시각 피드백

#### Haunt (구역 저주)

```
능력 사용: Echo가 검지를 땅에 대고 저주의 문양을 그림
          → 문양이 선택 위치로 확산되며 반경 8m 원형 영역 형성
          → 영역 경계는 지면에서 1.5m 높이까지 올라오는 옅은 안개 벽

적 감지 시: 영역 내 적 진입 → 안개 벽이 0.3초간 적색(#8b3a3a)으로 변색
           → 아군 HUD에 적 위치 핑 + 적 발밑에 2초간 발광 마커
           → Echo에게는 적의 실루엣이 2초간 Wireframe(청백색)으로 강조
```

#### Possess (오브젝트 빙의)

```
빙의 가능 오브젝트: Echo 시야에서 Soul Pale 아우라로 강조
빙의 진입: Echo가 오브젝트를 향해 손을 뻗음 → 영혼 입자가 오브젝트로 빨려들어감
          → Echo 아바타가 일시 소멸 (카메라는 오브젝트에 고정)

빙의 상태: 오브젝트가 미약하게 발광 (Echo 에너지가 오브젝트에 스며들었음을 표시)
          → 적 시야에서는 발광 강도 30%만 노출 (적대적 식별 가능하나 은밀성 보장)
          → 오브젝트 조작 시 오브젝트 주변에 영혼 입자가 일시 방출

빙의 해제: Echo가 오브젝트에서 빠져나옴 → 영혼 입자가 재결합하여 Echo 아바타 복원
```

#### Whisper (아군 메시지)

```
발신: Echo의 입가에서 영혼 입자가 일시적으로 밝아짐
      → 작은 빛 구체가 아군의 위치로 날아감 (이동 속도: 빠름. 약 0.3초)
      → 구체가 아군에게 도달하면 작은 빛 파동으로 흡수

수신 (생존자): 화면 모서리가 Echo 색조로 미약하게 깜빡임
              → UI에 메시지 도착 알림
              → 공간 오디오를 통해 Whisper 발신 방향의 음향 단서 제공
```

#### Soulflare (전맵 정찰)

```
충전: Echo가 두 손을 모아 에너지 구체를 응축
      → 충전 1.5초. 주변의 영혼 입자가 구체로 급속 유입
      → 충전 중 Echo 아바타 발광이 점점 강해짐 (적에게 발각 위험 증가)

발동: 구체가 수직으로 솟아오름 → Requiem 전역에 퍼지는 청백색 파동
      → 모든 생존자(적)의 위치가 아군 HUD에 2초간 노출
      → 적 화면에는 순간적인 청색 섬광 + "You have been revealed" 텍스트
      → 이후 파동의 잔상이 3초간 공중에 남음
```

#### Reclaim (부활)

```
충전 완료: Echo 아바타 발광이 최고조. 육안으로도 강한 Soul Bright 광원
          → Echo 아바타가 수직으로 상승하며 팔다리가 펼쳐짐
          → 주변의 영혼 입자가 급속히 아바타로 빨려들어감 (강한 VFX)

부활: 모든 입자가 한 점으로 수렴 → 폭발적 광원 → 생존자 아바타가 나타남
      → 0.5초간 백색 섬광 → 시야 회복과 함께 생존자 HUD 복원
      → 부활 지점에 반경 10m의 Echo 잔광 영역이 5초간 남음
      → 이 잔광은 적에게도 시각적으로 노출됨 ("누군가 여기서 부활했다")
```

### 3.4 아군/적군 Echo 시각 구분 체계

게임플레이 가독성을 최우선으로 하는 구분 체계:

| 식별 요소 | 아군 Echo | 적군 Echo |
|---|---|---|
| **발광 색상** | Soul Pale (#7eb8da) → 청백색 | 약화된 Soul Pale + 적대적 악센트 (#8b3a3a) → 탁한 청색에 붉은 잔광 |
| **실루엣** | 부드럽고 완전한 실루엣 | 날카롭고 파편화된 실루엣 (더 많은 입자 이탈) |
| **HUD 마커** | 영구적 Soul Pale 아이콘 (미니맵+월드) | 근접 시에만 Wireframe 강조 표시 (Echo Sight 사용 시 항시) |
| **움직임 궤적** | 미약한 입자 흔적. 0.5초 지속 | 흔적 없음 (은밀성 보장). 단, Echo Sight 활성화 시 적색 입자 흔적 |
| **Possess 오브젝트** | 청백색 발광 | 탁한 청색 + 미약한 적색 깜빡임 |
| **Dispel 가능 표시** | 없음 (Dispel 대상 아님) | Echo Sight 활성화 시 적 Echo 주변에 와해되는 원형 표적 |

**접근성 보완:** 모든 구분은 색상뿐 아니라 형상·움직임으로도 이중 인코딩 — 색각 이상 플레이어를 배려한 설계.

### 3.5 Echo 에너지 축적 시각화

| 에너지 레벨 | 아바타 변화 | 주변 환경 영향 |
|---|---|---|
| **0~33% (낮음)** | 발광 미약. 입자 이탈 많음. 불투명도 55% → 실루엣이 희미함 | 바닥 발광 영역 미미 |
| **34~66% (중간)** | 발광 안정화. 입자 이탈 감소. 불투명도 65% | 반경 1m 내 지면에 미약한 발광 |

| **100% (Reclaim 가능)** | 최대 발광. 불투명도 85%. 아바타 주변에 회전하는 입자 고리 | 반경 5m 발광 영역. 높은 생존자 피드백: 화면 가장자리에 청금색 파동 |

## 4. 소울라이크 감성 재해석

### 4.1 5대 미학 요소 — ECLIPSE: REQUIEM 버전

| 전통적 소울라이크 미학 | ECLIPSE: REQUIEM 재해석 | 적용 방법 |
|---|---|---|
| **숭고한 폐허** | **버려진 신성 (Abandoned Divinity)** | 신이 떠난 성소가 그대로 보존됨. 성스럽지만 황폐하지 않음. 관리자는 사라졌고 거주자만 남음. 건축은 정지된 몰락 상태에서 영원한 침묵 |
| **과장된 비율** | **영혼의 스케일 대비 (Soul vs Space)** | 인간 비례(영혼)와 비인간 스케일(건축)의 극단적 대비. 건축적 과장은 억압이 아니라 왜소함을 위한 것 |
| **훼손된 육체** | **파편화된 영혼 (Fragmented Soul)** | 육체 대신 영혼의 파편화. Echo 상태에서 팔다리 말단·등·어깨가 입자로 흩어짐. 에너지가 낮을수록 파편화 심화 — "영혼도 소모품이다" |
| **의식적 오브제** | **대상 없는 의식 (Ritual Without Object)** | 제단·촛불·향로는 존재하지만, 누구를 위한 것인지 아무도 기억하지 못함. 의식 도구 자체가 스스로 빛을 발함 |
| **환경 서사** | **정지된 순간들 (Frozen Moments)** | 각 공간은 어떤 사건이 발생한 '직후' 상태로 고정. 전복된 연회 테이블(Glutton's Gate), 무릎 꿇은 순례자 행렬(Ashen Cathedral) — 이 장면들은 결코 변하지 않음 |

### 4.2 요구사항 재해석 상세

#### 숭고한 폐허 (Sacred Ruin)

Requiem의 모든 건축은 **고딕 성당 건축의 3요소**를 따른다:
- **첨두 아치 (Pointed Arch):** 모든 개구부의 표준. 수직성을 강조하여 Pillar C 충족.
- **플라잉 버트레스 (Flying Buttress):** 구조적 요소가 외부로 노출된 형태. 건물의 '뼈대'가 보이는 미학.
- **리브 볼트 (Rib Vault):** 천장의 갈비뼈 구조가 그림자 대비를 극대화.

**추가 제약:**
- 유리는 모두 스테인드글라스. 그러나 자연광이 없으므로, 스테인드글라스는 자체 발광(바이오루미네선트) 또는 영혼의 빛이 투과된 상태.
- 식생은 죽었으나 썩지 않음. 나무는 잎 없이 가지만 남은 백골 상태. 덩굴은 화석화.
- 물은 존재하지 않음 — 대신 바닥에 정체된 안개(fog pool)가 액체의 역할을 대체.

#### 과장된 비율 — 영혼 스케일 대비

| 건축 요소 | 비율 규칙 | 예시 |
|---|---|---|
| **문** | 폭 1.2m × 높이 4~6m | 인간은 통과 가능하나, 문의 높이가 인간의 3~4배 |
| **열주 (기둥)** | 지름 1.5~2m × 높이 15~25m | 한 기둥 안에 인간 10명이 들어갈 수 있는 스케일 |
| **계단** | 단 높이 20cm × 단 너비 1.5m | 오르기 불편할 정도로 넓은 계단. 인간의 보폭에 맞지 않음 |
| **천장** | 실내 12~20m. 실외(성당 내부) 30m 이상. | 인간은 바닥에서 천장 디테일을 구분할 수 없음 — 의도된 정보 부족 |
| **아치** | 정점 높이 최소 8m | 모든 통로가 거대한 개구부를 통과하게 설계 |

#### 파편화된 영혼 — 훼손된 육체의 대체

**원칙:** Requiem에서 육체는 소모품이고, 영혼만이 지속된다. 육체의 훼손을 보여주는 대신, 영혼의 파편화를 보여준다.

| 적용 대상 | 표현 |
|---|---|
| **Echo 아바타** | 팔다리 말단이 입자로 흩어짐. 에너지가 낮을수록 파편화 영역 확대 (손목→팔꿈치→어깨 순) |
| **NPC Lost Soul** | 완전히 파편화된 영혼 — 인간 형태를 거의 알아볼 수 없을 정도. 빛 입자의 형체만 남음 |
| **사망한 적** | 사망 즉시 육체가 영혼 입자로 해체되어 Echo가 됨. 시체는 1초 이내에 사라짐 |
| **환경 내 잔상** | 과거 Requiem에서 소멸된 영혼들의 흔적이 건물 벽에 '얼룩'처럼 남음. 움직이지 않으나 미약하게 발광 |
| **군주 형상** | 군주는 영혼이 아닌 '영혼의 집합체' — 무수한 영혼 입자가 소용돌이치는 거대한 형상으로만 표현 |

#### 대상 없는 의식

- **제단:** 5개 군주에게 바쳐진 제단은 각 영역에 산재. 항상 타오르지 않는 촛불·바싹 마른 향로·비어 있는 제물 그릇이 배치됨.
- **촛불:** 모두 꺼져 있음. 단, 플레이어가 제단을 활성화하면 영혼의 빛으로 촛불이 다시 타오름(실제 불이 아닌 영혼 빛).
- **종:** 각 영역의 중심 건물에 하나씩 존재. 종은 깨져 있거나, 종추(clapper)가 사라짐. Mourning 이벤트 시 종이 스스로 울림.
- **성수반:** 비어 있으나, 바닥에 영혼의 잔광이 미약하게 남아 있음.

#### 정지된 순간들 — 환경 서사 방법론

환경 서사는 **"사건 발생 직후 0.5초에 시간이 멈췄다"** 는 원칙 아래 제작한다:

| 영역 | 정지된 순간 | 전달되는 서사 |
|---|---|---|
| **Sorrowfield** | 반쯤 내려간 석관 뚜껑. 관 밖으로 뻗은 손의 석상. | "누군가 매장을 거부했다. 아니면 매장된 자가 빠져나가려 했다." |
| **Glutton's Gate** | 전복된 연회 테이블 위, 깨지지 않은 마지막 잔 하나. | "마지막 축배를 든 자는 아무도 마시지 못했다." |
| **Obsidian Spire** | 무한히 뻗은 책장 사이, 딱 한 권만 바닥에 떨어져 있음. | "누군가 마지막 한 권을 찾았다. 그리고 그것을 떨어뜨렸다." |
| **Ashen Cathedral** | 무릎 꿇은 100구의 순례자 석상 행렬. 모두 같은 방향을 바라봄. | "그들은 무언가를 기다렸다. 그리고 그 무언가는 오지 않았다." |
| **Iron Crucible** | 벽에 박힌 수천 자루의 무기. 모두 부러져 있음. | "이곳은 무기고가 아니라 묘지다. 무기들의." |

## 5. 환경 아트 디렉션

### 5.1 Requiem 도시 전체 구조

Requiem은 **단일 거대 고딕 성당 도시**로, 5개 군주 영역이 유기적으로 연결된다. 맵 외곽은 "망각의 심연(Void)" — 안개 너머로 사라지는 공간.

```
맵 구조 (개념):
                    ┌──────────────┐
                    │   Glutton's  │
                    │     Gate     │
                    │   (GOLD)     │
                    └──────┬───────┘
                           │
    ┌──────────┐    ┌──────┴───────┐    ┌──────────┐
    │Obsidian  │    │   Ashen      │    │  Iron    │
    │  Spire   │────│  Cathedral   │────│Crucible  │
    │(VIOLET)  │    │  (CRIMSON)   │    │ (STEEL)  │
    └──────────┘    └──────┬───────┘    └──────────┘
                           │
                    ┌──────┴───────┐
                    │  Sorrowfield │
                    │    (BLUE)    │
                    └──────────────┘

    중앙: Ashen Cathedral — 모든 영역이 연결되는 허브
    외곽: 각 영역 끝에서 Void 안개로 페이드아웃
```

### 5.2 공간 전환 디자인

인접한 영역 간 경계는 **급격한 구분이 아닌 점진적 전환**으로 처리:

| 전환 구간 | 처리 방법 |
|---|---|
| **영역 A → 영역 B** | 20~30m의 전환 지대. 양 영역의 시그니처 색조가 혼합. 건축 스타일이 점진적으로 변화. 안개 밀도가 증가하여 원거리 시야 차단 |
| **실내 → 실외** | 항상 아치를 통한 통과. 아치 통과 시 자동 노출(exposure) 조정으로 시야 전환 |
| **지상 → 지하** | 계단·경사로를 통한 수직 이동. 조명이 청색 비율 증가(영혼 빛 의존도 상승) |
| **영역 내부 → Void** | 건축물이 점차 붕괴되고, 안개가 짙어지며, 채도가 0으로 수렴. Zone 가장자리에서 이 전환을 활용 |

### 5.3 Requiem의 파도(Zone) 시각화

Zone은 단순한 원형 수축이 아니라 **각 군주 영역의 시그니처를 가진 시각적 현상**:

| 영역 | Zone 형태 | 시각화 |
|---|---|---|
| **Grief** | 안개가 바닥에서부터 천천히 차오름. 지하 공간을 먼저 채움 | Mourning Blue 안개. 수면처럼 잔잔. 접촉 시 영혼 입자가 아래로 스며들 듯 소멸 |
| **Hunger** | 그림자가 수축. 모든 인공 광원(촛불·횃불)이 순차적으로 꺼짐 | Famine Amber 잔광이 점점 좁아짐. 접촉 시 아바타가 재로 분해 |
| **Obsession** | 공중에 떠 있는 성운이 내려앉음 | Obsession Violet 구름. 접촉 시 아바타가 데이터처럼 픽셀화 소멸 |
| **Despair** | 불이 완전히 꺼지며 어둠이 확장 | 잿빛 진홍 어둠. 접촉 시 아바타가 숯으로 변해 붕괴 |
| **Wrath** | 바닥에서 균열이 발생하며 그 안으로 모든 것이 빨려들어감 | Quenched Steel 충격파. 접촉 시 파쇄 효과로 소멸 |

각 Zone의 이동 방식은 비대칭 — PVS(Potentially Visible Set) 계산과 연동하여 구현.

### 5.4 Mourning & Judgment 이벤트

| 이벤트 | 시각화 | 지속 |
|---|---|---|
| **Mourning** | 전역 안개 농도 2배 증가. 모든 광원의 가시 거리가 50%로 감소. AI 몹의 눈(Caustic 발광)만이 안개 속에서 강조됨. 깨진 종이 스스로 울리며 원형의 충격파 VFX 발생. | 60초 |
| **Judgment** | 하늘(천장)에 5개 군주의 심볼이 순차적으로 나타났다 소멸. 각 보급품 위치에서 수직으로 올라가는 빛 기둥이 10초간 표시됨. 이후 빛 기둥은 소멸하고 미니맵에만 마커 유지. | 30초 |

### 6.3 Soul Fragment 아우라 스케일링

| Fragment 수 | 아우라 강도 | 반경 | 적에게 보이는 거리 | 시각적 묘사 |

| 0 | 없음 | — | — | — |
| 1~2 | 15% | 0.5m | 근접(5m 이내) | 미약한 발광 외곽선 |
| 3~5 | 30% | 1m | 중거리(15m 이내) | 반경 1m의 구형 발광. 벽에 반사 |

## 7. 조명 원칙

### 7.1 근본 규칙

```
Rule 0: Requiem에는 태양이 없다. 모든 빛은 영혼에서 비롯된다.
Rule 1: 광원이 없는 곳은 완전한 흑(#000000)이 아니라 Soul Void (#0a0810)로 표현한다.
Rule 2: 빛은 항상 국소적이다. 글로벌 일루미네이션은 잔광(bounce) 수준에 그친다.
Rule 3: 영혼의 빛은 따뜻하지도 차갑지도 않다 — 청백색(#7eb8da 기반)의 중성 온도다.
Rule 4: 모든 인공 광원(촛불·횃불·용광로)도 본질적으로 영혼의 빛을 흡수했다가 재발산하는 매개체다.
```

### 7.4 그림자 규칙

- 모든 그림자는 **소프트 섀도(soft shadow)** — Requiem에는 직사광이 없으므로 경성 그림자(hard shadow)가 존재하지 않는다.
- 영혼체는 그림자를 드리우지 않는다. 대신 바닥에 미약한 발광 영역(caustic-like)을 형성.
- 건축물 그림자는 영역별 시그니처 색조를 미묘하게 띤다 (Grief 구역 그림자 → 청색 틴트 등).

## 11. VFX 원칙

| 원칙 | 내용 |
|---|---|
| **모든 VFX의 소재는 영혼 입자** | 불꽃·연기·물보라 같은 물리적 현상이 아닌, 빛나는 영혼 입자가 모든 VFX의 기본 단위 |
| **게임플레이 우선** | 모든 능력 VFX는 '무엇이 일어나고 있는가'를 0.3초 안에 전달해야 함 |
| **거리 기반 디졸브** | 원거리(30m+)의 VFX는 2D 스프라이트로 단순화. 이펙트 품질이 아니라 정보 전달에 충실 |
| **색상은 기능과 정합** | 적대적 VFX → 적색 악센트 포함. 아군 VFX → 순수 Soul Pale. 중립 VFX → 영역 시그니처 색조 |
