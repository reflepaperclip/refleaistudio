## 1. 개요

본 문서는 ECLIPSE: REQUIEM 게임제안서에 대한 게임 디자인 상세 검토로서, 크리에이티브 디렉터가 제시한 조건부 승인 5개 조건 중 **조건 2(Echo 재미 원천 정밀 정의)** 를 주축으로 다음 5개 영역을 분석하고 설계 대안을 제시한다:

1. **Echo 재미 원천 분석** — Self-Determination Theory 기반 심리 욕구 충족 경로와 측정 기준
2. **예상 메타 플레이 패턴 분석** — 창작 검토에서 제기된 emergent play 패턴의 설계 의도 부합성 판정 및 대응
3. **Heretic 클래스 재설계** — 스노우볼링 리스크 해소를 위한 대안 설계
4. **Penitent(탱커) 역할 재정의** — BR 장르에 적합한 탱커 개념으로의 전환
5. **Echo vs 생존자 밸런스 원칙** — 비교 불가능한 두 플레이 상태 간의 힘의 균형 원칙 구체화

## 2. Echo 재미 원천 분석 (조건 2)

### 2.1 플레이어 판타지

Echo 상태의 플레이어 판타지는 **"죽었지만 끝나지 않은 전사"** 다. 생존자는 총을 쏘고, 이동하고, 파밍하는 BR의 기본 동사를 수행한다. Echo는 정보를 수집하고, 환경을 조작하며, 결정적 순간에 개입하는 전략가의 동사를 수행한다. 이 두 경험은 **비교 불가능할 정도로 달라야 하며**, 그것이 Echo가 "생존보다 재미없다"는 비교를 원천 차단하는 방법이다.

### 2.2 SDT 기반 심리 욕구 충족 분석

#### 2.2.1 자율성 (Autonomy)

**현재 설계에서의 충족 경로:**

| 자율성 요소 | Echo 상태에서의 발현 | 강도 |
|---|---|---|
| 능력 선택의 자유 | 5개 Echo 능력 중 상황에 맞는 선택 (Haunt/Possess/Whisper/Soulflare/Reclaim) | 높음 |
| 공간적 자율성 | 전장 전체를 자유롭게 이동 (벽 통과 가능, 생존자의 물리적 제약 없음) | 매우 높음 |
| 시점 선택의 자유 | Haunt 위치 선정, Possess 대상 오브젝트 선택, Soulflare 발동 타이밍 | 높음 |
| 자원 배분의 자유 | Echo 에너지를 Reclaim에 투자할지 Soulflare에 투자할지 결정 | 중간 |
| 역할 전환의 자유 | 정보 수집자, 방해자, 부활 도전자 등 역할을 동적으로 전환 | 중간 |

**자율성의 역설과 해결:**
Echo는 생존자보다 물리적으로 더 자유롭다(벽 통과, 중력 무시). 그러나 행동 레퍼토리는 생존자보다 좁다(전투 불가, 오브젝트 상호작용 제한). 이 **"더 넓은 공간, 더 좁은 행동"** 의 역설이 Echo 고유의 플레이 경험을 정의한다.

**설계 권고:**
- Echo 능력의 사용 횟수에 인위적 제한을 두지 않고 에너지 경제로 자연스러운 제약을 건다. "몇 번 쓸 수 있다"보다 "에너지가 있으면 쓸 수 있다"가 자율성을 높인다.
- Possess 대상 오브젝트를 카테고리별(문·함정·조명·환경 오브젝트)로 구분하여, 각 카테고리에서 다른 전략적 선택지를 제공한다. 같은 '문'도 열고/닫고/잠그는 3가지 조작이 가능해야 Possess의 자율성이 의미를 갖는다.

#### 2.2.2 유능감 (Competence)

**현재 설계에서의 충족 경로:**

| 유능감 요소 | Echo 상태에서의 발현 | 강도 | 문제점 |
|---|---|---|---|
| 직접적 기여 | Haunt로 적 위치 노출 → 아군이 처치 | 낮음 | **기여의 귀속이 불분명**. 아군이 Haunt 정보로 킬을 해도 Echo 플레이어에게 귀속되는 피드백 없음 |
| 경쟁적 우위 | 타 Echo Dispel로 에너지 획득, Echo 간 심리전 | 중간 | Echo-Echo 상호작용은 직접적이지만 보상(에너지)의 가시성이 낮음 |
| 숙련도 곡선 | Haunt 최적 위치 학습, Possess 최적 타이밍 축적 | 중간 | 숙련도 향상이 수치화되지 않아 성장감 부재 |
| 전략적 예측 | 적의 이동 경로를 예측한 선제적 Haunt 배치 | 중간 | 성공/실패 피드백이 지연되고 모호함 |
| 결정적 기여 | Soulflare로 전세 역전, Reclaim으로 극적 컴백 | 높음 | 이 순간은 강력하나 빈도가 너무 낮음 (매치당 1회 이하) |

**핵심 문제: 유능감의 귀속성(Attribution) 결여**

Echo의 가장 큰 유능감 설계 과제는 **"내가 한 일이 승리에 기여했다는 것을 어떻게 알 수 있는가"** 이다. 생존자는 적을 처치하면 킬 피드가 뜨고, 데미지 숫자가 보이고, 전리품을 획득한다. Echo의 기여는 대부분 간접적이며, 현재 설계에서는 그 성과가 생존자의 행동을 통해 간접 실현된다.

**설계 권고 — 유능감 피드백 장치:**

| 피드백 장치 | 설명 | 구현 우선순위 |
|---|---|---|
| **Echo 어시스트 통계** | "내 Haunt로 노출된 적이 15초 내 사망" → Echo 어시스트 판정 및 매치 종료 후 하이라이트 | P0 |
| **Haunt 성공 피드백** | Haunt 구역에 적이 진입했을 때 시각적·음향적 신호 (Echo 플레이어에게만 "네 함정이 발동했다"는 피드백) | P0 |
| **Possess 성과 로그** | Possess로 조작한 오브젝트가 적의 이동을 방해하거나 피해를 입혔을 때 피드백 | P1 |
| **Whisper 가치 평가** | Whisper 이후 팀원의 행동 변화(이동 경로 변경·전투 회피·매복)를 Whisper의 성과로 기록 | P2 |
| **Echo MVP 시스템** | 매치 종료 후 Echo 기여도 기준 별도 MVP 선정 ("올해의 유령상" 등) | P1 |
| **Echo 기여의 시각화** | 아군 생존자 화면에 "팀원 Echo가 Haunt로 적 발견" 알림을 명시적으로 표시 | P0 |

#### 2.2.3 관계성 (Relatedness)

**현재 설계에서의 충족 경로:**

| 관계성 요소 | Echo 상태에서의 발현 | 강도 | 문제점 |
|---|---|---|---|
| 팀 소속감 | Whisper로 생존 팀원과 소통, Echo에서 팀 전략에 기여 | 중간 | Whisper가 3회로 제한되어 지속적 소통 불가. "유령은 말을 아껴야 한다"는 판타지는 있으나 너무 적음 |
| 동료 의식 | 같은 팀의 다른 사망자와 Echo 상태에서 협력 | 없음 | **현재 설계에서 누락.** 동시에 2명 이상의 팀원이 Echo일 때의 상호작용이 설계되지 않음 |
| 경쟁 관계 | 적 Echo와의 Dispel 경쟁 | 낮음 | Echo-Echo Dispel은 존재하나, 이 상호작용에 서사적·감정적 무게가 없음 |
| 동맹 관계 | Pact 체결 (생존 상태 한정) | 낮음 | Echo 상태에서는 Pact와 무관하여 외교적 축에서 소외됨 |

**핵심 발견: 2인 Echo 협력의 설계 공백**

3인 스쿼드 체제에서 2명이 사망하고 1명이 생존한 상황은 가장 빈번한 극적 순간이다. 현재 설계는 2명의 Echo가 같은 팀 생존자를 위해 어떻게 협력할 수 있는지 정의하지 않았다.

**설계 권고 — 공동 Echo 메커니즘:**

| 메커니즘 | 설명 |
|---|---|
| **Soul Link** | 동일 팀 Echo 2인이 일정 거리 내에 있을 때 Echo 에너지 회복 속도가 30% 증가. 함께 행동하는 것을 장려 |
| **Combined Haunt** | 2명의 Echo가 같은 구역에 Haunt 중첩 시 효과 강화 (감지 범위 1.5배, 지속 시간 1.3배). 협력의 보상 |
| **Whisper Boost** | 동일 팀 Echo가 근처에 있을 때 생존자에게 전달 가능한 Whisper 횟수 +2회. 함께 있을 때 소통 능력 향상 |
| **Twin Dispel** | 2명의 Echo가 협력하여 적 Echo를 Dispel하면 소모 에너지 20% 절감 |

#### 2.2.4 몰입(Flow) 상태 설계

| 몰입 조건 | Echo 상태에서의 설계 | 평가 |
|---|---|---|
| **명확한 목표** | "생존 팀원을 승리로 이끈다" + "Reclaim으로 부활한다" | 명확함. 두 목표가 상충할 때(에너지 투자 선택)의 긴장이 추가적 몰입을 창출 |
| **즉각적 피드백** | Haunt 발동, 적 감지, Possess 조작, Dispel 성공 | **부족.** 유능감 귀속성 문제(2.2.2)와 동일 |
| **난이도-능력 균형** | Echo 능력은 실행 난이도가 낮으나 전략적 판단 난이도가 높음 | 적절. "쉽게 쓰지만 어렵게 잘 쓴다"는 구조 |
| **행동-인식 융합** | Echo의 모든 행동이 전략적 의도를 담고 있음 (무의미한 행동 없음) | 우수 |
| **시간 왜곡** | 생존자의 전투 템포와 Echo의 전략 템포가 시간 감각을 다르게 함 | 긍정적. 매치 중반 Echo의 관망 시간이 지루해지지 않도록 Soul Fragment 수집·Echo 간 상호작용의 밀도를 유지해야 함 |
| **통제감** | Echo는 물리적 위협에서 자유로우나 정보적 통제권을 가짐 | 적절 |

### 2.3 정량적 측정 기준

프리프로덕션 플레이테스트에서 수집할 핵심 지표를 정의한다:

| 측정 지표 | 측정 방법 | 목표치 | 의사결정 임계값 |
|---|---|---|---|
| **Echo 참여 지속률** | 사망 후 Echo 상태에서 3분 이상 활동 지속한 비율 | ≥ 80% | < 50% → Echo 경험 재설계 필요 |
| **Echo 능력 사용 빈도** | Echo 상태 분당 능력 사용 횟수 | ≥ 2.0회/분 | < 1.0회/분 → 능력 비용 또는 접근성 조정 |
| **Echo 기여 전환율** | Echo 어시스트 / 전체 Echo 능력 사용 횟수 | ≥ 25% | < 15% → 유능감 피드백 장치 보강 |
| **Reclaim 성공률** | Reclaim 시도 중 실제 부활 성공 비율 | 15~30% | > 50% → Reclaim 비용 증가 (너무 쉬움) < 5% → Reclaim 비용 감소 또는 부활 조건 완화 |
| **Soulflare 영향력** | Soulflare 발동 후 10초 내 아군이 적 처치한 비율 | ≥ 40% | < 20% → Soulflare 노출 시간 증가 또는 비용 감소 |
| **Echo 이탈률** | Echo 상태가 된 플레이어가 매치를 완전히 떠나는 비율 | ≤ 15% | ≥ 30% → Echo 근본 재미 실패 신호 |
| **Dispel 상호작용률** | Echo 상태에서 적 Echo와 Dispel 상호작용을 1회 이상 한 비율 | ≥ 40% | < 20% → Echo-Echo 상호작용 기회 부족 |

### 2.4 정성적 측정 기준

플레이테스트 직후 수집하는 플레이어 응답 항목:

| 질문 | 척도 | 목표치 |
|---|---|---|
| "Echo 상태에서도 게임이 재미있었다" | 5점 리커트 | 평균 ≥ 3.5 |
| "Echo가 없으면 ECLIPSE: REQUIEM은 덜 재미있을 것 같다" | 5점 리커트 | 평균 ≥ 4.0 |
| "Echo 상태에서 내 행동이 팀 승리에 기여했다고 느꼈다" | 5점 리커트 | 평균 ≥ 3.5 |
| "사망 후에도 매치의 일부라고 느꼈다" | 5점 리커트 | 평균 ≥ 4.0 |
| "Echo 상태가 너무 강력해서 일부러 죽는 것을 고려했다" | 5점 리커트 | 평균 ≤ 2.0 |
| "Echo 상태보다 생존 상태가 더 재미있었다" | 5점 리커트 | 평균 ≥ 3.5 |

### 2.5 Echo 경제 곡선

Echo 상태의 경험을 시간축에서 분석하면 다음 단계로 구성된다:

```
사망 (0분)
  │
  ├── 0~1분: Echo 적응기
  │   ├── 기본 에너지 100 획득
  │   ├── Echo 전용 튜토리얼 HUD 활성화
  │   └── "이제 당신은 Echo입니다" 전환 연출
  │
  ├── 1~5분: Echo 전성기
  │   ├── 능력 비용이 감당 가능한 수준 (주로 Haunt/Possess/Whisper)
  │   ├── 생존 팀원 지원에 집중
  │   ├── 적 Echo 발견 시 Dispel 기회
  │   └── Soulflare 또는 Reclaim을 위한 에너지 축적 결정
  │
  ├── 5~10분: Echo 전략기
  │   ├── 에너지가 충분하다면 Soulflare 발동 → 게임 체인저
  │   ├── 에너지를 모아 Reclaim 도전 → 부활
  │   ├── Dispel 당하면 에너지 손실 → 전략 재수립
  │   └── Zone 접근 시 도주 또는 Haunt 재배치
  │
  └── 10분~종료: Echo 말기
      ├── Soulflare가 이미 사용되었다면 정보 제공에 전념
      ├── Reclaim 성공 시 생존자로 복귀
      ├── Zone에 잠식되면 소멸
      └── 팀 승리 시 특별 Echo 승리 연출
```

이 곡선에서 **1~5분 구간이 Echo 재미의 핵심**이다. 이 구간에서 "죽었지만 할 일이 있다"는 느낌이 강하게 유지되어야 한다.

## 3. 예상 메타 플레이 패턴 분석

### 3.1 개요

크리에이티브 디렉터의 창작 검토(MDA 갭 1)에서 제기된 emergent dynamics를 분석하고, 각 패턴이 설계 의도와 부합하는지 판정한다.

| 메타 패턴 | 설계 의도 부합 | 판정 | 대응 |
|---|---|---|---|
| 자살 후 Echo 전환 정보 수집 전담 | 부분적 | RED — 게임 근간 위협 | 하드 카운터 설계 |
| Soul Fragment 아우라 미끼 전략 | 부분적 | YELLOW — 리스크/리워드 재조정 필요 | 튜닝 노브로 제어 |
| 생존 팀원 1명 + Echo 2명의 극단적 정보 우위 | 부분적 | YELLOW — 2인 Echo 협력 의도적 설계 필요 | 2.2.3의 공동 Echo 메커니즘 적용 |
| 팀 전원 Echo 후 Reclaim 동시 도전 | 의도치 않음 | RED — 전원 사망이 전략적 최적해가 됨 | Reclaim 팀 제한 강화 |
| 초반 Wraith 사냥으로 Soul Fragment 독점 | 의도적 | GREEN — PvE 파밍 경로로서 허용 | 모니터링만 필요 |

### 3.2 패턴 1: 자살 후 Echo 전환 — 정보 수집 전담

**전략 설명:**
한 팀원이 의도적으로 초반에 사망(자살 또는 적에게 자발적 노출)하여 Echo 상태로 전환한 뒤, 5개 능력을 전부 Haunt와 Possess에 집중 투자하여 팀의 전담 정보 요원으로 활동한다. 생존 팀원 2명은 이 정보를 바탕으로 교전을 유리하게 이끈다.

**최적해 분석:**

| 요소 | 자살 Echo 전략 | 정상 플레이 |
|---|---|---|
| 팀 생존자 수 | 2명 | 3명 |
| 총 화력 | 2인분 | 3인분 |
| 정보력 | Echo 1인이 제공하는 360도 시야 + Haunt | 제한적 |
| Soul Fragment 수급 | 생존자 2인이 수급, Echo 1인은 소극적 | 3인이 수급 |
| Reclaim 가능성 | Echo 1인이 모으면 1명 부활 → 3인 복구 | 사망 시 1명만 Echo |
| 전략적 유연성 | Echo가 사망하지 않으므로 지속적 정보 제공 | 사망 시 Echo 전환까지 공백 |

**판정: 의도치 않은 최적해.** 3인 전원 생존보다 2인 생존 + 1인 Echo가 **정보력 측면에서 우위**를 가진다면, Echo 능력의 의도된 밸런스를 넘어선 것이다.

**대응 설계:**

| 대응 방안 | 설명 | 효과 |
|---|---|---|
| **자살 페널티** | 자의적 사망(환경 낙사·자살 명령·2분 이내 전투 없이 사망) 시 Echo 에너지 50%만 획득하고, Echo 능력 쿨다운 30초 추가 | 자살의 기회비용을 높여 정상 전투 후 사망이 더 유리하도록 설계 |
| **Echo 능력 위력의 생존 시간 비례** | 생존 상태에서 5분 이상 생존 후 사망한 Echo는 능력 위력이 100%, 3분 미만 생존 후 사망한 Echo는 70%로 감소 | 초반 자살이 Echo 품질을 낮추도록 유도 |
| **팀 Echo 수 비례 에너지 감쇠** | 동일 팀에 Echo가 2명 이상일 때 에너지 자연 회복 속도가 30% 감소 | 다수 Echo 전략의 지속성을 제한 |
| **Haunt의 생존자 의존성** | Haunt는 Echo가 아니라 생존 팀원이 해당 구역에 진입해야만 '활성화'됨. Echo 혼자서는 정보 획득 불가 | Echo의 정보 수집을 위해 생존자의 이동이 필요하게 만듦 |

**권고:** 자살 페널티 + Echo 능력 위력 생존 시간 비례를 1차 방어선으로, Haunt의 생존자 의존성을 구조적 제약으로 채택한다.

### 3.3 패턴 2: Soul Fragment 아우라 미끼

**전략 설명:**
Soul Fragment를 대량 보유한 플레이어가 제단에서 소모하지 않고, 의도적으로 아우라를 노출시켜 적을 유인한 뒤 매복한다. Fragment가 드롭되지 않도록 제단에서 소모하기 직전까지 아우라를 유지하며 '걸어 다니는 미끼' 역할을 한다.

**분석:**
이 패턴은 설계 의도 범위 내에 있으나, Fragment 드롭(사망 시 50%)으로 인한 손실 리스크가 미끼 전략의 가치를 상쇄할 수 있다. 미끼가 사망하면 Fragment의 50%를 적에게 넘겨주기 때문이다.

**튜닝 노브:**

| 파라미터 | 현재값 | 조정 방향 |
|---|---|---|
| Fragment 드롭률 | 50% | 60~70%로 증가 — 미끼 전략의 리스크를 높임 |
| 아우라 강도 곡선 | 선형 (Fragment 수 비례) | 비선형: 0~2 약함, 3~5 중간, 6+ 강함 — 미끼가 기능하려면 일정량 이상 보유해야만 유인 효과 발휘 |
| 제단 소모 보너스 | Fragment 소모 시 일괄 동일 보상 | 대량 소모 시 보너스 배율 (10개 일괄 소모 시 일반 보상의 1.3배). "아우라를 오래 유지할 이유"를 감소 |

**권고:** 아우라 비선형 곡선 + Fragment 대량 소모 보너스를 도입하여 "아우라 미끼"를 고위험 전략적 선택지로 남기되, 무분별한 미끼 플레이를 억제한다.

### 3.4 패턴 3: 팀 전원 Echo 후 Reclaim 동시 도전

**전략 설명:**
3명 모두 사망 → 3명 모두 Echo 상태에서 에너지 집중 수집 → 3명이 동시에 Reclaim을 시도하여 팀 전체가 부활. 이 전략이 가능하다면 "전멸이 오히려 기회"라는 역설이 발생한다.

**현재 설계의 취약점:**
제안서는 "Reclaim: 3킬 분량의 Echo 에너지 축적 → 부활, **매치당 최대 1회, 팀당 최대 1명**"으로 정의했다. 그러나 이 제한은 **팀당 1명**이므로 3명이 각자 Reclaim을 시도할 때 어떤 순서로 처리되는지 정의되어 있지 않다.

**대응 설계:**

| 사항 | 규칙 |
|---|---|
| **Reclaim 선착순** | 팀당 1명만 Reclaim 가능. 가장 먼저 Reclaim 조건을 충족한 1인이 부활. 나머지 2인은 에너지를 Soulflare에 투자하도록 유도 |
| **Reclaim 쿨다운 (팀)** | 팀 Reclaim 1회 발생 후 3분간 같은 팀의 추가 Reclaim 불가 |
| **Reclaim 시 에너지 공유** | Reclaim을 하지 않는 팀원의 Echo 에너지 일부(30%)가 Reclaim 시도 팀원에게 이전되어 성공 확률 상승. "너는 부활하고 우리는 Soulflare로 지원한다"는 협력 구도 형성 |

**권고:** 선착순 + Reclaim 불가 팀원의 에너지 지원 시스템을 도입하여, 팀 전원 Reclaim이 아닌 1인 Reclaim + 2인 Soulflare라는 전략적 분업을 유도한다.

### 3.5 패턴 4: Pacifist Echo — 전투 회피 후 Echo로만 활동

**전략 설명:**
생존 상태에서는 전투를 완전히 회피하고(Wraith만 사냥, 적 조우 시 도주), 오로지 Echo 상태에서의 활동만을 목표로 하는 플레이 스타일. "나는 Echo일 때가 진짜 실력 발휘다"라는 접근.

**판정:** 의도치 않음. Echo는 보조적 경험이어야 하며, Echo를 '목적'으로 삼는 플레이를 허용해서는 안 된다. 동시에, 생존 상태를 두려워하는 플레이어에게 Echo가 '도피처'가 되어서도 안 된다.

**대응 설계:**

| 대응 | 설명 |
|---|---|
| **생존 보너스** | 생존 시간 5분당 Echo 상태의 기본 에너지 +15%. 오래 살아남을수록 더 강한 Echo가 된다. 생존 회피 전략의 기회비용 증가 |
| **Echo 킬 비가산** | Echo 상태에서의 Dispel 성과는 최종 킬/어시스트 통계와 별도로 집계. Echo만으로는 계정 진행(Mastery, Requiem Favor 등)이 불가능하도록 설계 |
| **Echo 의존도 노출** | 매치 종료 후 "생존 기여도 vs Echo 기여도" 비율을 시각화. 전체 플레이어 평균과 자신의 비율을 비교 제공 |

## 4. Heretic 클래스 재설계

### 4.1 현행 설계 분석

**현행:**
> "처치할수록 스킬 쿨다운 감소 (무제한 중첩, 사망 시 리셋)"

**스노우볼링 메커니즘 분석:**

| 매치 단계 | Heretic 상태 | 타 클래스와의 격차 |
|---|---|---|
| 초반 (0~5분) | 0~1킬: 쿨다운 정상. 평균적 위력 | 없음 |
| 중반 (5~15분) | 3~5킬: 쿨다운 30~50% 감소. 지속 딜링 능력 급증 | **격차 발생 시작** — 동일 무기·아이템 레벨 기준 Heretic > 타 원거리 클래스 |
| 후반 (15분~) | 7~10킬: 쿨다운 70~100% 감소. 스킬 난사 상태 | **격차 폭발** — Heretic의 DPS가 스킬 쿨다운 무시 수준에 도달. 1:2 상황도 승리 가능 |

**근본 문제:**
1. **양성 피드백 루프**: 실력 우위 → 더 많은 킬 → 더 빠른 쿨다운 → 더 쉬운 킬 → 더 많은 킬 → ...
2. **캐치업 불가**: Heretic 상대에게는 "초반에 막지 못하면 게임 끝"이라는 절망적 내러티브 발생
3. **팀 의존도 저하**: Heretic이 혼자서도 해결되는 화력을 가지면 팀플레이 동기 감소

### 4.2 재설계 원칙

| 원칙 | 설명 |
|---|---|
| **상한선 존재** | 무제한 성장은 BR 장르의 긴장감을 파괴한다. 언제나 역전 가능성은 존재해야 한다 |
| **감쇠 메커니즘** | 획득한 힘은 유지 비용이 있어야 한다. 쉬지 않고 싸워야 유지되는 힘 |
| **리스크 동반** | 강해질수록 노출 리스크도 증가해야 한다. Soul Fragment 아우라 메커니즘과 유사한 원리 |
| **다양한 획득 경로** | 처치뿐 아니라 다양한 플레이로 중첩을 쌓을 수 있어야 클래스의 전략적 깊이가 증가한다 |

### 4.3 대안 설계

#### 대안 A: 상한선 + 시간 감쇠 (권고)

**설계:**
- 처치 시 "분노(Wrath)" 중첩 1 획득. 중첩당 스킬 쿨다운 5% 감소
- **최대 10중첩 (최대 50% 쿨다운 감소)**
- **중첩은 60초마다 1개씩 자연 감소** (전투가 없으면 힘이 식는다)
- 사망 시 모든 중첩 소멸
- **어시스트도 0.5중첩 획득** — 팀플레이 기여 보상

**효과:**
- 최대 50% 쿨다운 감소는 강력하나 무한 스노우볼링 방지
- 감쇠로 인해 지속적 전투 참여 요구 — 캠핑 억제
- 어시스트 보상으로 팀플레이 유도

**튜닝 노브:**

| 파라미터 | 기본값 | 권장 범위 |
|---|---|---|
| 중첩당 쿨다운 감소율 | 5% | 3~7% |
| 최대 중첩 | 10 | 8~15 |
| 감쇠 주기 | 60초 | 45~90초 |
| 어시스트 중첩 | 0.5 | 0.33~1.0 |

#### 대안 B: 피해 누적 기반

**설계:**
- 적에게 입힌 피해량이 "분노 게이지"를 충전
- 게이지 100% 도달 시 "분노 폭발" 발동 — 15초간 스킬 쿨다운 60% 감소
- 발동 후 게이지 0으로 리셋
- 생존 시간 경과에 따라 게이지 자연 충전 (30초당 5%)

**효과:**
- 처치뿐 아니라 견제·압박 플레이도 보상 → 전략적 다양성 증가
- 피해 누적이므로 Heretic이 불리한 상황에서도 게이지를 쌓을 수 있음 (캐치업 가능성)
- '폭발 타이밍'을 선택하는 전략적 깊이

**단점:**
- '분노 폭발' 발동 타이밍을 연기할 수 있다면(게이지 100% 유지), 강한 순간을 저장하는 전략이 가능해짐 → 의도되지 않은 메타 가능성

#### 대안 C: 생존 시간 기반 (대안적 접근)

**설계:**
- 생존 시간 2분마다 쿨다운 10% 감소 (최대 50%)
- 자신이 입힌 피해량에 따라 가속 (피해를 많이 입힐수록 중첩 속도 증가)
- 사망 시 리셋

**효과:**
- 처치 실패자도 시간이 지나면 강해짐 → 역전 가능성 제공
- 적극적 전투가 가속을 제공하지만, 생존만으로도 최대 중첩 달성 가능
- 소극적 플레이어의 안전망

**단점:**
- 생존 시간이 절대적 강함을 보장하면 후반 Heretic이 너무 강해질 위험
- 처치 기반에 비해 '실력에 의한 성장'의 만족감이 낮음

#### 권고

**대안 A(상한선 + 시간 감쇠) + 대안 B(처치 대체 경로)의 혼합을 권고한다.**

최종 설계 제안:

```
Heretic — "분노의 불길" (재설계)

기본기:
- 처치 시 [분노] 중첩 1 획득
- 어시스트 시 [분노] 중첩 0.5 획득
- [분노] 중첩당 스킬 쿨다운 5% 감소
- 최대 10중첩 (50% 쿨다운 감소)
- 매 60초마다 [분노] 중첩 1 감소
- 사망 시 모든 [분노] 중첩 소멸

추가 획득 경로:
- 연속 피해 (5초 내 피해량 100 이상) — [분노] 중첩 0.25 획득
- 보스(Lord's Vassal) 처치 기여 — [분노] 중첩 2 획득
- Echo Dispel — [분노] 중첩 0.5 획득

시각적 피드백:
- 1~3중첩: 미약한 붉은 오라
- 4~7중첩: 눈에 띄는 화염 오라 (아군·적군 모두 시인 가능)
- 8~10중첩: 강렬한 지옥불 오라 + 이동 속도 흔적 — 위치 노출 증가
  → Heretic이 강해질수록 Soul Fragment 아우라와 유사하게 시각적 리스크 증가

디자인 의도:
- 10중첩 상태는 "이 플레이어가 지금 맵에서 가장 위험한 존재"라는 정보를 모든 플레이어에게 전달
- 강함 = 가시성이라는 원칙을 Heretic에도 적용
```

### 4.4 Heretic 재설계의 MDA 검증

| 레이어 | 효과 |
|---|---|
| **메커닉스** | 무제한 중첩 → 최대 10중첩 + 시간 감쇠 + 어시스트·연속 피해 등 추가 획득 경로 |
| **다이내믹스** | 지속적 교전 참여 독려(감쇠), 팀플레이 보상(어시스트), 역전 가능성(캐치업 경로), 정보 게임(오라 시각화) |
| **에스테틱스** | "점점 더 위험해지는 적"이라는 긴장감, "최대 중첩을 유지하기 위한 사냥꾼"이라는 플레이어 판타지, "저 불길을 꺼야 한다"는 적의 행동 유도 |

## 5. Penitent(탱커) 역할 재정의

### 5.1 현행 설계의 구조적 문제

**현행:** "주변 아군의 피해 일부를 대신 받음"

BR 장르에서 탱커 개념이 작동하지 않는 이유:

| 문제 | 설명 |
|---|---|
| **피해 폭발성** | BR의 교전은 짧고 치명적이다. 저격 헤드샷·샷건 근접사격은 단일 피해량이 매우 크며, 이 피해를 '흡수'한다는 설계는 탱커의 즉사로 이어진다 |
| **정보 비대칭** | 아군이 받을 피해를 탱커가 미리 알 수 없다. MOBA처럼 예측 가능한 스킬 기반 전투가 아님 |
| **위치 의존성** | "주변 아군"이라는 반경 제한은 BR의 분산된 교전·엄폐물 활용과 상충. 뭉쳐 다니면 수류탄·광역기에 취약 |
| **수동적 역할** | 탱커는 피해를 '받는' 역할이므로, 플레이어의 능동적 의사결정 기회가 적다. 재미의 핵심인 자율성 충족에 실패 |

### 5.2 BR 장르에 적합한 탱커 정의

BR에서 '탱커'의 진정한 가치는 **피해를 흡수하는 것**이 아니라 **적의 선택지를 제한하는 것**이다.

**새로운 정의: "공간 점유자 (Space Denier)"**

Penitent는 전장의 특정 공간을 점유하여 적의 이동·사격·정보 획득을 방해한다. 탱킹은 체력이 아니라 **공간 통제**를 통해 실현된다.

### 5.3 재설계: Penitent 능력 세트

#### 기본 능력 1: "고해성사 (Confession)"

| 항목 | 내용 |
|---|---|
| 효과 | 전방에 폭 8m, 깊이 15m의 신성한 장막을 12초간 생성 |
| 장막 효과 | 내부의 아군은 받는 피해 20% 감소. 외부의 적은 장막을 통과해 사격 시 탄환이 30% 확률로 빗나감 (정확도 감소) |
| 전략적 용도 | 좁은 통로·입구에 설치해 적의 진입을 억제. 아군이 안전하게 회복·재정비할 공간 확보 |
| 시각적 표현 | 반투명한 비탄의 베일. 내부에서는 외부가 보이지만 약간 흐릿하게, 외부에서는 내부가 거의 보이지 않음 |
| 쿨다운 | 45초 (지속 시간 포함 시 가동률 약 21%) |

#### 기본 능력 2: "속죄의 발걸음 (Penitent's March)"

| 항목 | 내용 |
|---|---|
| 효과 | 6초간 이동 속도 30% 감소하지만 넉백·슬로우·스턴에 면역이 되고, 이동 경로에 3초간 지속되는 "고행의 흔적"을 남김 |
| 흔적 효과 | 적이 흔적 위를 지나면 2초간 이동 속도 50% 감소. 아군이 흔적 위를 지나면 2초간 이동 속도 20% 증가 |
| 전략적 용도 | 적의 퇴로를 차단하거나, 아군의 진입로를 확보하는 이중 목적 |
| 쿨다운 | 25초 |

#### 궁극기: "비탄의 성소 (Sanctuary of Grief)"

| 항목 | 내용 |
|---|---|
| 효과 | 반경 10m의 원형 성소를 15초간 생성 |

| 전략적 용도 | 최종 존에서의 공간 장악. 적이 강제로 진입해야 하는 구역에 설치해 교전을 유리하게. 적이 성소 밖에 머물면 Zone에 잠식되고, 안에 들어오면 약화됨 |

| 쿨다운 | 180초 |

## 6. Echo vs 생존자 밸런스 원칙

### 6.1 밸런스 원칙 선언

> **Echo 상태는 생존 상태보다 '약하지만', 생존 상태만으로는 얻을 수 없는 고유 가치를 제공한다. 이 두 경험은 비교 불가능하며, 각각 플레이어에게 다른 종류의 만족을 제공한다.**

### 6.2 밸런스 축 정의

| 축 | 생존자 | Echo | 비교 가능? |
|---|---|---|---|
| **전투력** | 직접 데미지, 킬 가능 | 데미지 불가 (Dispel은 Echo 대상만) | **불가** — Echo는 전투력이 '0'이므로 이 축으로 비교할 수 없음 |
| **이동 자유도** | 지상 이동, 점프, 장애물 존재 | 벽 통과, 중력 무시, 전장 어디든 접근 | **불가** — 다른 차원의 이동 |
| **정보력** | 시야 기반, Seeker 능력으로 제한적 확장 | 360도 시야 + Haunt + Soulflare | **Echo 우위** — 이 축에서 Echo가 독점적 가치를 제공 |
| **생존력** | 체력·방어구 존재, 치유 가능 | 물리적 피해 면역, Dispel에만 취약 | **Echo 우위** — 대신 Zone에 잠식되면 소멸 |
| **성장력** | Soul Fragment 수집, 제단 Blessing, 장비 파밍 | Echo 에너지 축적, Dispel로 에너지 탈취 | **비교 불가** — 다른 성장 축 |
| **팀 기여** | 화력·어시스트·부활 지원(Penitent 능력) | 정보·방해·일시적 부활(Reclaim) | **보완적** — 상호 보완 관계 |

### 6.3 밸런스 안전장치

| 안전장치 | 설명 | 위반 시 징후 |
|---|---|---|
| **Echo 전투력 0 원칙** | Echo는 어떤 형태로든 적 생존자에게 직접 피해를 줄 수 없다 | Echo가 함정·Possess 오브젝트로 적을 죽일 수 있다면 위반 |
| **Echo 의존 억제** | 생존자가 "Echo가 없으면 게임이 안 된다"고 느껴서는 안 된다. Echo는 보조다 | Echo 의존도 메타 발생. 생존자 단독 플레이 선택률 20% 미만 시 경고 |
| **Reclaim 희소성** | Reclaim의 기회비용은 항상 높아야 한다. "Reclaim 시도가 항상 옳다"가 되어서는 안 된다 | Reclaim 시도율 80% 초과 시 Reclaim 비용 상향 |
| **생존자 Echo 대응 수단** | Dispel Crystal, Echo Sight, Soul Harvest가 항상 Echo 정보 우위를 상쇄할 수 있어야 한다 | Echo 정보로 인한 교전 승률이 대응 아이템 보유 팀과 미보유 팀 간 20%p 이상 차이 |
| **Echo 시간 제한** | Echo는 Zone에 잠식되면 소멸한다. 무한정 Echo 상태를 유지할 수 없다 | 평균 Echo 생존 시간이 15분 초과 시 Zone 속도 상향 또는 Echo 에너지 자연 감소 도입 |

### 6.4 "Echo가 생존보다 재미없다"는 비교를 차단하는 설계 원칙

| 원칙 | 설계 적용 |
|---|---|
| **다른 장르의 경험** | 생존자는 FPS/TPS. Echo는 실시간 전략(RTS)에 가까운 경험. Haunt 위치·Possess 오브젝트·에너지 투자 결정은 타워 디펜스·자원 관리의 재미 |
| **다른 시간 감각** | 생존자는 초 단위 교전 템포. Echo는 분 단위 전략 템포. Echo의 '관망 시간'도 전략적 계산으로 채워지게 설계 |
| **다른 승리 기여** | 생존자는 "적을 죽이는 것"으로 기여. Echo는 "적이 죽을 상황을 만드는 것"으로 기여. 매치 종료 후 두 기여를 별도로 평가 |

### 6.5 플레이테스트 검증 항목

| 검증 항목 | 방법 | 기대 결과 |
|---|---|---|
| Echo 능력의 위력 만족도 | Echo 플레이어 대상 설문. 5개 능력 각각에 대해 "이 능력이 유용했다" 4점 이상 | Haunt ≥ 4.0, Soulflare ≥ 4.5, Possess ≥ 3.5 |
| 생존자의 Echo 대응 만족도 | 생존자 대상 설문. "Echo가 나를 방해하는 것이 불공정하게 느껴졌다" 2점 이하 | 평균 ≤ 2.0 |
| Echo 선호율 | "생존 상태와 Echo 상태 중 어떤 상태를 더 선호하는가" | 생존 65~80%, Echo 20~35% |
| Echo가 매치 결과에 미친 영향 | 매치 종료 시 "Echo 기여가 승리에 결정적이었다"고 응답한 팀 비율 | 25~45% |

## 10. 인수 기준

### 10.1 Echo 재미 원천

- [ ] SDT 3개 축(자율성·유능감·관계성)에 대한 Echo 경험 설계가 문서화되었고, 축별 강점과 약점이 식별되었다
- [ ] 각 SDT 축의 정성적 측정 기준(리커트 설문)과 정량적 측정 기준(게임플레이 텔레메트리)이 정의되었다
- [ ] 유능감의 '귀속성 문제'에 대한 대응 설계(Echo 어시스트 통계, Haunt 성공 피드백 등)가 제시되었다
- [ ] 2인 Echo 협력 메커니즘(Soul Link, Combined Haunt 등)이 정의되었다
- [ ] Echo 경험의 시간축 곡선(적응기→전성기→전략기→말기)이 정의되었다

### 10.2 메타 플레이 패턴

- [ ] 주요 emergent play 패턴 5개가 식별·분석되었고, 각 패턴의 설계 의도 부합성이 판정되었다
- [ ] RED 판정 패턴(자살 Echo, 전원 Reclaim)에 대한 하드 카운터 설계가 제시되었다
- [ ] YELLOW 판정 패턴(Soul Fragment 미끼, 2인 Echo 협력)의 튜닝 노브와 대응 설계가 제시되었다
- [ ] 모든 대응 설계가 3대 축(Pillar)을 위반하지 않음을 검증했다

### 10.3 Heretic 재설계

- [ ] 무제한 중첩이 제거되고, 상한선(50%)과 시간 감쇠(60초당 1중첩)가 도입되었다
- [ ] 처치 외의 중첩 획득 경로(어시스트, 연속 피해, 보스 기여, Echo Dispel)가 추가되었다
- [ ] 높은 중첩 상태의 시각적 노출(오라)이 정의되어 리스크-리워드 균형이 강화되었다
- [ ] 스노우볼링이 최대 50%로 제한되어 후반 역전 가능성이 보장된다

### 10.4 Penitent 재정의

- [ ] 피해 흡수 기반 탱커 개념이 폐기되고, 공간 점유 기반(Confession, Sanctuary, Penitent's March)으로 재설계되었다
- [ ] 모든 Penitent 능력이 능동적 플레이어 의사결정(공간 선택·타이밍·리소스 투자)을 요구한다
- [ ] Penitent의 간접 기여 모델이 Pillar 3(Victory Must Be Earned)에 부합한다

### 10.5 Echo vs 생존자 밸런스

- [ ] "비교 불가능한 두 경험"이라는 원칙이 6개 밸런스 축(전투력, 이동 자유도, 정보력, 생존력, 성장력, 팀 기여)으로 구체화되었다
- [ ] 5개 밸런스 안전장치(Echo 전투력 0, Echo 의존 억제, Reclaim 희소성, 생존자 대응 수단, Echo 시간 제한)가 정의되었다
- [ ] 각 안전장치의 위반 시 징후와 대응 지표가 정의되었다
- [ ] 플레이테스트 검증 항목 4개가 정의되었다
